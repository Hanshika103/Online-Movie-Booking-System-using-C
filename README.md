# 🎬 Online Movie Booking System (C Project)

This project is a console-based Online Movie Booking System developed in C. It simulates a real-world ticket booking experience where users can register, explore movies, and manage their bookings efficiently.

## Features:
#### 🔐 User Registration & Login system
#### 🎥 View available movie details
#### 🪑 Check seat availability
#### ⏰ View show timings (slots)
#### 💰 Check ticket pricing
#### ❌ Cancel booked tickets
## ⚙️ Project Highlights:
##### Built using C programming language
##### Uses structured programming concepts (functions, arrays, structures)
##### Menu-driven interface for smooth navigation
##### Beginner-friendly implementation of booking logic
##### Demonstrates real-world system simulation
## 🎯 Purpose:

This project helps understand core C programming concepts while building a practical system similar to real online movie ticket booking platforms.
